简介

PROFILE

从游戏效果、渲染管线，到 Unity Runtime 的源码修改。 我的工作主要围绕实时画面、性能和多平台稳定性展开。

早期做 CocosCreator 与 Laya 游戏客户端，2021 年起转向实时渲染。 目前在无端参与大型开放世界项目的 Unity 引擎源码和自定义 SRP 维护， 负责多线程渲染、GPU 资源路径、调试工具与跨平台问题。熟悉把效果需求拆成 Pass、资源和同步问题，也愿意补工具与流程，让性能和稳定性可以持续验证。

01 引擎底层

在 Unity Runtime 中实现 GPU MeshCombine、SRP Threaded 抓帧和 Vulkan 视频资源路径。

02 渲染管线与并发

维护自定义 SRP，推进管线全面三线程化，把发起、数据准备、提交与收尾放到 SRP 线程，并处理天空、后效、GTAO 等 Pass 的同步与画质分级。

03 商业项目交付

覆盖 PC、Android、iOS、OpenHarmony 与海外版本，和策划、美术、QA、平台团队长期协作。
